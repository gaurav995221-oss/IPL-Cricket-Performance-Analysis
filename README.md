# IPL-Cricket-Performance-Analysis
A Python-based IPL Cricket Data Analysis project that explores batting statistics, compares player performances, and visualizes cricket insights using Pandas, NumPy, and Matplotlib.
# 🏏 IPL Cricket Performance Analysis using Python

## 📌 About the Project
This project focuses on analysing IPL 2026 batting statistics using Python. It explores the performance of the top 30 run scorers and presents useful insights through data analysis and visualisation.

The project is developed as a beginner-level college project to understand the practical applications of Python in Data Analytics.

## 🎯 Project Objectives
- Analyse IPL batting statistics.
- Identify the top run scorers.
- Compare players based on batting average and strike rate.
- Analyse fours and sixes scored by players.
- Create graphs to represent cricket performance visually.

## 🛠️ Technologies Used
- **Python** – Programming language
- **Pandas** – Data handling and analysis
- **Matplotlib** – Data visualisation
- **CSV** – Dataset format
- **VS Code** – Development environment

## 📊 Dataset Description

The dataset contains batting statistics of the top 30 run scorers from the IPL 2026 leaderboard.

| Column | Description |
|---|---|
| Player | Player name |
| Team | IPL team |
| Matches | Matches played |
| Innings | Innings played |
| Runs | Total runs scored |
| Batting_Average | Batting average |
| Strike_Rate | Batting strike rate |
| Fours | Number of fours |
| Sixes | Number of sixes |

**Note:** This is a top-30 leaderboard dataset, not the complete IPL historical dataset.

## 📈 Analysis Performed

1. Top 10 run scorers.
2. Player batting average comparison.
3. Strike rate comparison.
4. Total fours and sixes analysis.
5. Graphical comparison of player performances.
